# Quick start

1. Start with an isolated browser profile and disable browser sync.
2. Install the unpacked extension (see [installation](INSTALLATION.md)).
3. Open the extension dashboard; initial bookmark detection is automatic.
4. Click **Analyze / sync** and inspect the statistics, Original tree and suggested categories.
5. Use filters to investigate low-confidence items, duplicates and category overlaps.
6. Select items; approve or correct individual destinations. Uncertain items remain unchanged.
7. Click **Preview plan**. Inspect the destination and number of proposed mutations.
8. Click **Apply this approved plan** once. The extension first stores a recoverable snapshot.
9. Inspect the resulting browser folder tree. If needed, open Backups and select **Undo / compensating rollback**.
10. Export a portable backup before removing the extension.

Only the explicit application step moves, creates or renames bookmarks. You do **not** need to export HTML files to apply the result.
