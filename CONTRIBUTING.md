# Contributing

Please use English for new source documentation, comments, commit messages and issue descriptions. Run `npm run check`, `npm test` and `npm run benchmark` before submitting code. Test browser-side changes in disposable profiles with browser sync disabled.

Do not include actual bookmark files, profile data, API keys, internal websites, private URLs or unredacted screenshots in issues or pull requests. Add synthetic regression fixtures for bugs and describe observed browser versions and test results. This is a local-first project; permissions and consent boundaries require careful review.
