Backups, restore and recovery
Every browser modification starts with an integrity-checked snapshot. Interrupted batches stop for recovery. Restore preserves externally added bookmarks and may retain their folders.
To redo, restore the snapshot automatically created just before undo. Cross-profile restores are rejected.


Automation, models and privacy
Auto-Organize
Only authorized rules with confidence ≥95% run automatically. No automatic deletions. Ambiguous bookmarks stay in the review queue.


Optional AI and safe website inspection
The manager works offline without a server. For AI and page metadata, run npm start, set BOOKMARK_EXTENSION_ID to this extension ID, open http://127.0.0.1:3210/pair, and copy its pairing token here. Only the selected bookmarks are sent to a configured model after consent.
Metadata requests use four workers, bounded responses and timeouts. Analysis checkpoints every 100 items. Results are cached by content and configuration.


Local data is not browser-sync storage. Back up before uninstalling. HTML compatibility tools remain in the optional local companion.
